# Demo script — target 1 minute 45 seconds

Record the functioning application. Before claiming AI generation, connect Azure and show a successful provider label. Avoid exposing keys or account details.

0:00–0:15: “The scoreline tells us what happened. PRO-VISION AI helps explain why a moment matters, using original synthetic football events.” Show the dashboard and data label.

0:15–0:35: Play replay, then pause on a shot or turnover. “The pitch shows recorded ball actions while the statistics update. This is an event schematic, not footage.”

0:35–0:55: Select a progressive pass or pressure event. “The explanation connects the action with its context and exposes the evidence IDs.” If Azure is active, name the actual service and show its provider label.

0:55–1:15: Switch fan to coach mode and filter a team. “The same evidence supports different experiences: accessible context for fans, passing detail and review prompts for coaches.”

1:15–1:35: Advance replay, create a recap and download it. “The recap uses only events up to this point. The original dataset is also available.”

1:35–1:45: “PRO-VISION AI makes the match explorable, explainable and personal. Next we will extend synthetic streaming inputs and broadcast overlays.”

Do not claim video recognition, multi-agent systems or helmet integration. Upload a video shorter than two minutes to an accepted public host and test its link signed out.
