# Free local entry path

No paid cloud deployment is needed for this test-build approach. Foundry Local uses the entrant/judge computer. Initial SDK/runtime/model downloads and hardware requirements apply. The rules permit a functioning test build, but installation must be repeatable and software must match the video.

## Decisions

- Keep real Microsoft Phi inference and clearly distinguish accepted AI from computed fallback.
- Compute statistics and evidence independently of generation speed.
- Use short grounded fan/broadcast rewriting and a separately evaluated analyst task.
- Retain synthetic-data labeling, bounded event context, unsupported-question handling and personal memory privacy.
- Keep NFC clothing and helmet hardware as concepts; neither is implemented.
