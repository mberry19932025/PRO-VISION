# PRO-VISION — draft entry pitch

PRO-VISION helps viewers understand a football moment and keep their own story of it. An original synthetic event stream powers replay, measured statistics, transparent pattern rules and personalized explanations for fans, analysts and broadcasters. Microsoft Phi-3.5-mini runs locally through Foundry Local, with bounded evidence, output checks and visibly computed fallback when generation fails.

Viewers can inspect each cited event, compare audience lenses, choose a player or language, and see how removing a pressure record changes the computed signal. A visible processing record separates source boundaries from interpretation. A source-linked recovery-to-shot interval connects the recorded build-up to analyst review without claiming speed or causation. Timed overlay records and an automated template recap can be exported. Fans can attach a personal note/photo and download an interactive keepsake linked to their selected moment; clothing interaction is a clearly labeled simulation.

Local inference uses an isolated worker so the server can terminate a stalled generation. Identical previously checked answers may be reused from a bounded, explicitly labeled cache. Fresh generation and cache retrieval timings are reported separately. The software runs without a paid cloud model subscription.

The prototype currently uses nine authored events, not a complete match or real footage. Spanish computed explanations work; broad multilingual AI reliability is unverified. It is a bounded generation workflow, not an autonomous multi-agent system. Hardware, actual NFC scans and XtremeSignPost integration are future concepts.

Microsoft technologies actually tested: Foundry Local SDK 2.1.0 and Microsoft Phi-3.5-mini. The entrant created a Foundry cloud project, but the attempted model deployment was blocked by quota; no successful Azure inference or deployment is claimed. GitHub hosts the public source; the provided workflow example is not an installed CI pipeline.

Before using this pitch in a submission, confirm category fit, test a clean install on another supported computer, finish browser QA, and publish the actual demonstration video under two minutes. Current local checks do not establish judge-platform compatibility or production readiness.
