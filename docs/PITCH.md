# PRO-VISION — draft entry pitch

Football viewers see the action, but often miss why it matters. PRO-VISION turns a synthetic football event stream into evidence-linked match intelligence for fans, analysts and broadcast teams.

The prototype computes recorded statistics and football signals, replays the action on an original pitch graphic, and generates tentative explanations using Microsoft Phi-3.5-mini through Foundry Local in a local Node app. Viewers can choose a club, player and language. Three lenses offer accessible fan explanations, analyst measurements/review prompts, and a compact broadcast graphic. Every explanation links to its source events. An evidence lab demonstrates how removing a pressure record changes a computed signal. A recap and timed overlay record can be exported.

The original PRO-VISION document inspires the multi-perspective experience and replay controls. The hackathon submission is newly built association-football software using fictional clubs and players; the helmet remains a longer-term concept.
